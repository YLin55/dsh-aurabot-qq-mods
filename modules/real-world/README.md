# 小世界（real-world）

> 给她和你一个专属的小世界：地区内短途、地区间长途都按真实时间走，地图预设可存多套，存档按人格隔离；每晚回访会改写地点、调整偏好，她挑自己更喜欢的地方去——你也可以邀她出门。

给她一个「有地点、有时间表」的活动范围：她自己申报去哪儿、为什么去，路上会按阶段知道自己在哪；
地图由你定义，而且会随着她的经历慢慢变化。

## 它怎么运作

1. **时间表**：外出时段默认 `10:00–22:00`，移动间隔默认 `2 小时`（面板可改）。
2. **载入即在家**：第一次跑（或换了人格还没有存档）默认待在地图里的「家」。
3. **到点提醒**：到点推一条系统提醒，让她从当前地区选地点、写理由。这个提醒固定触发（100%），节奏只由「移动间隔」决定。
4. **移动有耗时**：申报后不是瞬移，而是按距离走完再落位（详见「移动耗时」）。
5. **记录**：真正到达后才写进「今天的路线」，含地点、时间、理由。
6. **每轮注入**：每次回话前带上当前位置——平时是地点，路上是「移动中 / 长途移动中」：

   ```
   【你现在在哪】<地图名> · <地区> · <地点>——<这地方是什么样>。
   （来这里的理由：……；14:02 到的。）
   ```

   路上则变成：

   ```
   【你现在在哪】<地图名> · <地区> · 移动中——正从「A」走往「B」。
   你要前往B，现在从A走路前往B，还要约 9 分钟。
   （出发地：A · 地区；目的地：地区 · B；去那里的理由：……）
   ```

7. **静默时间跟着时段走**：时段外不催换地方、不发汇报。
8. **三个松绑开关**（默认关/开，见设置页）：
   - **允许她自己出门**：关掉后完全不催申报
   - **允许晚回一小时**：结束时间点多出「再待一小时」
   - **允许夜不归宿**：结束时间点多出「今晚不回家」；选了晚回会在一小时后再问一次

### 时间窗

| 时间段 | 行为 |
|---|---|
| 开始时间前 | 完全静默 |
| 外出时段内 | 到点提醒定地点；没申报 10 分钟后催一次；到地点后按开关汇报 |
| 结束时间 ~ 结束+1 小时 | 晚回 / 夜不归宿一起问一次（再待一小时 / 今晚不回家 / 现在回家） |
| 结束+1 小时 之后 | 选了晚回就再问一次今晚回不回家；其余静默 |

## 地图结构：地图 → 地区 → 地点

```
地图预设（可以有多张）
└── 地区（一张地图里可以有多个）
    └── 地点（每个地区自带一个「车站」）
```

- **地区尺度约方圆 2 公里**：一段步行/短途能走完的街区，跨地区才算出远门
- **每个地区必须有「车站」**：新建地区自动带上，固定卡删不掉；**站名和简介可以改**（改成驿站、传送点都行）
- **「家」只在一个地区**：整张地图只有一处家
- **切换地图 / 地区**：面板里切换只是换「正在查看/编辑」的对象，不影响她现在的位置；要她真的过去用命令或工具
- 每张地点卡 = 地点名 + 一句简介（她每轮读到的“这地方是什么样”）+ 可选标签：`💰 打工`、`❤️ 情色`

## 面板

顶部三个标签：

| 标签 | 内容 |
|---|---|
| 📊 状态 | 现在在哪 · 今日路线（30 秒刷新）；路上显示行程进度 |
| ⚙️ 设置 | 所有开关与参数（见「设置项」） |
| 🗺️ 地图 | 地图预设、平面地图、地区与地点卡片 |

设置页按逻辑排列：总开关 → 外出时段与节奏 → 长途方式 → 汇报（开关在上、参数缩进在下）→ 晚回/夜不归宿 → 每晚总结。

## 平面地图

每个地区一张方图（约 2km × 2km）：

- **点圆点**：右侧显示/编辑地点（名字、简介、图标、喜好权重、坐标）；改完点「保存修改」直接落盘，
  不想改了点「取消」。「家」名字锁定，车站可以改名
- **缩放**：地图右下角滑块 1x~3x + 百分比 + 「复位」；放大后**按住左键拖拽**平移，拖到边界会停住
  （不会拖出地图外）。缩放/平移后落点坐标照样准
- **点选 vs 拖拽**：按下后位移不超过 3px 才算「点选地点」，超过就当作拖拽平移，松手不会误加点
- **移动所选地点**：先点地点，再点地图空位，可反复点换位置，虚线会连出原位置；「保存到地区」前都算预览，「取消」可反悔
- **添加地点**：点地图空位落点 → 填名字简介（可选图标/权重）→ 保存；有「取消」可以退出
- **删除地点**：选中后点「删除地点」，两步确认；「家」和「车站」不能删
- **图标**：12 个预设 `🏠 🚉 📍 💼 ❤️ 🛁 🍜 ☕ 🎹 🌸 🍺 🏨`，编辑区点一下就选中，右边「默认」清掉；
  地点卡片上的图标**点一下循环切下一个**。留空时按默认规则显示：车站 🚉 / 家 🏠 / 有「打工」标签 💼 / 其它 📍
- **喜好权重**：0~200，越高她越倾向去那儿（每晚回访也会自己调）；「家」和「车站」不参与，没有这一栏
- **最小间距**：两个地点至少隔开地图的 9%（约 180 m）。放太近会被拒绝并提示，自动落点也会自动避开
- **自动落点**：没有坐标的地点会按「四分区取最少的一块 → 随机锚点 → 随机角度挤开」找位置
- **未保存提示**：「保存地区」按钮只在真有改动时才亮。判定方式是比「当前地点指纹」和「上次保存的指纹」——
  改了再改回原样会**自动熄灭**（顺序无关的标签集合、四舍五入到 0.0001 的坐标都按同一口径比较）；
  地图上还有未提交的草稿（新增/移动预览）时也算有改动

## 地图背景

每个地区可以有自己的背景，随地区保存：

| 预设 | 画面 |
|---|---|
| 都市 | 街区网格 + 主干道 + 河 |
| 乡村 | 田块 + 田埂 + 土路 + 村舍 |
| 郊外 | 弯曲小路 + 散落房子 + 行道树 + 水塘 |
| 山野 | 山体 + 小溪 + 虚线小径 |
| 异世界 | 羊皮纸底 + 城墙王城与塔楼 + 雪顶山脉 + 森林 + 河 + 土路 + 罗盘（剑与魔法的中世纪风） |

- **导入自定义图片**：前端缩到最长边 1024、转 JPEG 后上传（后端上限 2MB）
- **无背景**：回到默认网格
- 背景只是底图，不参与坐标与最小间距计算

## 移动耗时

申报移动后先排一段行程，**路上只改位置提示，到点才真正落位**：

| 情况 | 流程 |
|---|---|
| 同地区 | 按直线距离：每 100 m 约 2 分钟；提示「你要前往B，现在从A走路前往B」 |
| 跨地区 | ① 走到**当前地区的车站**（同公式）→ ② 坐长途（时长、手段见设置）→ ③ 从目的地区车站走到目标地点（同公式） |

三段对应的位置提示：

```
【你现在在哪】… · 地区 · 移动中——正从「A」走往「车站」。
你要前往B，现在从A走路前往车站坐电车前往B地区，还要约 6 分钟。

【你现在在哪】… · 途中 · 长途移动中——正坐电车从A地区前往B地区。
你要前往B，现在正坐电车从A地区前往B地区，还要约 15 分钟。

【你现在在哪】… · B地区 · 移动中——正从「B地区车站」走往「B」。
你要前往B，现在从B地区车站走路前往B，还要约 7 分钟。
```

- 全部本地推进：每分钟检查一次，到点就挪到这一段的目标
- 期间没有消息也照常走完；只有对话时才注入对应阶段的提示
- 坐车时地区显示「途中」，站名、地区名、交通手段都取自数据与设置
- 走完最后一段才记进路线，并触发出门汇报（如果开着）

## 申报与汇报

**到点申报**：固定 100%，只受两个因素影响——「允许她自己出门」开关和「移动间隔」。
模块启动（含改文件触发的热重载）时，如果下次提醒时间已经过期，会自动顺延一个间隔，不会一重启就催她。

**换地方后的主动汇报**才按概率 + 间隔：

| 设置 | 默认 | 说明 |
|---|---|---|
| `reportOnMove` | 开 | 汇报总开关 |
| `reportChance` | `100` | 汇报触发概率（%） |
| `reportMinGapMinutes` | `120` | 两次汇报最小间隔（默认 2 小时 = 移动间隔） |

出发那一刻不汇报，等真正到达才报；刚聊过天或主人刚说过话也不打断。

## 每晚地点回访（默认 23:30）

把今天去过的地方（地点、时间、理由、当前描述）交给模型，重写每个地点“对你而言现在是什么样”，写回地图：

- 只改今天去过的地点；新描述覆盖 `info`，原来那句存进 `infoBase`
- 同一天只跑一次；没去过任何地方就跳过
- 手动触发：`/小世界 总结`

## 工具

| 工具 | 作用 |
|---|---|
| `real_world_move(region?, place, reason)` | 申报地区 + 地点 + 理由（会按距离排行程） |
| `real_world_plan(lateReturn?, overnight?, reason?)` | 决定晚回 / 夜不归宿 |
| `real_world_status()` | 位置或行程进度、今日路线、**所有地区**的地点（含喜好权重）、下次提醒时间 |

## 命令（QQ 里发）

```
/小世界                     看状态（路上会显示第几段、还要多久）
/小世界 帮助                用法
/小世界 今日                今天的行程
/小世界 地图                地图预设列表
/小世界 新地图 <名字>        新建地图
/小世界 切地图 <序号或名字>   切换地图
/小世界 地区                地区列表 + 当前地区可选地点
/小世界 新地区 <名字>        新建地区（自带车站）
/小世界 切地区 <序号或名字>   真的过去（落到该地区车站）
/小世界 晚归 开|关           允许晚回一小时
/小世界 夜不归宿 开|关        允许夜不归宿
/小世界 去 <地点> [理由]      让她去某处（同样会走行程）
/小世界 总结                现在跑一次地点回访
/小世界 重置                清空今天的路线
```

别名：`/在哪`、`/位置`；只有主人能用。

命令里的状态是**精简版**（位置 / 目的 / 下次移动），完整的「所有地区 + 地点 + 权重」只在
`real_world_status` 工具里给模型看——这两条口径分开维护（`commandStatusText()` / `statusText()`），
别把整张地点表塞进聊天命令里。

## 设置项

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | 开 | 总开关 |
| `allowSelfOuting` | 开 | 允许她自己出门；关掉就没有到点申报 |
| `startTime` / `endTime` | `10:00` / `22:00` | 外出时段 |
| `intervalHours` | `2` | 移动间隔，也是申报节奏 |
| `chatProtectMinutes` | `10` | 主人刚说过话时不催她换地方 |
| `rideMode` | `电车` | 长途手段，**自由输入**（马车 / 飞艇 / 传送阵都行） |
| `rideMinutes` | `15` | 长途那一段的时长（分钟） |
| `reportOnMove` | 开 | 换地方后主动汇报 |
| `reportChance` | `100` | 汇报概率（%） |
| `reportMinGapMinutes` | `120` | 汇报最小间隔（分钟） |
| `allowLateReturn` | 关 | 允许晚回一小时 |
| `allowOvernight` | 关 | 允许夜不归宿 |
| `reflectEnabled` | 开 | 每晚地点回访 |
| `reflectTime` | `23:30` | 回访时间 |

## 数据（按人格分开存）

```
modules-data/real-world/personas/<人格id>.json
```

包含：地图预设与地区、地点（含坐标 `x`/`y`）、地区背景（`bg`）、当前位置与理由、行程 `travel`、
今天的路线、风格样例、下次提醒时间、晚回/夜不归宿。

- 切到没有存档的人格：自动生成一张默认地图（一个地区 + 家 + 车站）
- 跨天：只重置路线和晚回/夜不归宿
- 地点简介被回访改写后，原句留在 `infoBase`
